# Todo List React — Kanban Board

Aplicação de gerenciamento de tarefas inspirada em ferramentas Kanban como Trello e Jira.

Projeto desenvolvido com foco em prática real de React, componentização, gerenciamento de estado e organização de aplicações frontend.

---

## Funcionalidades

- Criar tarefas
- Remover tarefas
- Alterar status das tarefas
- Organização em Kanban Board
- Persistência com LocalStorage
- Navegação entre páginas com React Router
- Interface moderna responsiva
- Componentização reutilizável

---

## Conceitos praticados

- React
