# React To Do List

Projeto de estudos desenvolvido com React e Vite.

## Funcionalidades

- Adicionar tarefas
- Remover tarefas
- Concluir tarefas

## Tecnologias

- React
- Vite
- CSS3

## Aprendizados

Projeto criado para praticar:
- useState
- props
- componentização
- renderização dinâmica
- eventos
- manipulação de arrays
